# Política de segurança

## Versões suportadas

A versão em desenvolvimento é a única suportada durante a fase Alpha.

## Relato de vulnerabilidades

Não publique credenciais, provas de conceito exploráveis ou dados sensíveis em issues públicas. Utilize o recurso **Security > Report a vulnerability** do GitHub, quando habilitado, ou entre em contato de forma privada com o mantenedor do repositório.

Informe: descrição, impacto, passos mínimos para reprodução e sugestão de mitigação. O recebimento será confirmado assim que possível.

## Escopo atual

O frontend estático não possui autenticação, banco de dados, coleta de credenciais, anúncios ou scripts externos. Chaves de API nunca devem ser incluídas no frontend ou versionadas no repositório.
