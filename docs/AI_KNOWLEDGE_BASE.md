# Base de conhecimento do Copiloto

O índice do copiloto será formado por registros estruturados e documentos oficiais vinculados a instrumento, obra, conta, pagamento, medição ou vistoria.

Cada fragmento indexado deve conter: URL oficial, sistema de origem, identificador, data de coleta, hash do arquivo/payload, classificação documental, vínculo de domínio e permissões de publicidade.

A resposta deve separar:
- fatos literais da fonte;
- cálculos determinísticos da plataforma;
- ausência de informação.

A geração é bloqueada quando não houver evidência recuperada. Não há preenchimento de lacunas por conhecimento geral do modelo.
