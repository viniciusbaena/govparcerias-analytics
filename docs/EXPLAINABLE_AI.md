# IA explicável

Toda resposta factual deve separar:

1. fatos oficiais;
2. cálculos determinísticos da plataforma;
3. inferências permitidas e explicitamente rotuladas;
4. limitações e dados não localizados;
5. evidências com sistema, URL, identificador, data de coleta, hash e trecho/página quando documental.

Sem evidência recuperada, a resposta factual é bloqueada.
