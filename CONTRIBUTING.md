# Como contribuir

1. Abra uma issue descrevendo a melhoria ou correção.
2. Crie uma branch a partir de `main`.
3. Mantenha a interface sem dependências externas desnecessárias.
4. Não inclua credenciais, dados restritos ou informações pessoais.
5. Execute as validações locais antes do pull request.
6. Atualize a documentação quando alterar comportamento público.

## Convenções

- Código e documentação em português do Brasil.
- Dados demonstrativos devem ser claramente identificados.
- Dados reais devem apresentar fonte e data de atualização.
- O projeto não deve utilizar marcas ou sugerir vínculo institucional não autorizado.
